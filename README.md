# STL Studio · 牙模可视化工具

参考牙模查看页面的独立前端工具。顶部步骤栏、浅灰画布、沙金色牙模、标准视角，可同时查看多个 STL / OBJ。使用 TypeScript、Vite、Three.js，无后端；上传的文件仅在浏览器本地读取，不发送到服务器。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd "D:\工作\CYY\AI口腔\瑞通\排牙软件\STL可视化工具"
npm.cmd ci
npm.cmd run dev
```

打开 http://127.0.0.1:5186 。默认进入“模型预处理”的上传页面，不自动打开固定病例。点击“选择牙模文件”，也可直接拖入一个或多个 STL / OBJ 文件。刷新后需重新上传。

也可双击 `start.cmd` 启动，首次运行会安装依赖。

## 使用

- 顶部步骤依次为模型预处理、分牙、初始位模型、治疗计划、目标位、分步、附件。目前仅实现模型预处理的可视化，其余步骤显示“该功能还在开发中”。
- 咬合碰撞、模型调整仅提供开发中占位页面。切换步骤后返回模型预处理会保留已上传的模型、视角及网格状态；不会执行任何预处理或治疗计算。
- 默认无网格时使用 35° 视场角的透视投影。点击顶部“网格”开启正交投影及屏幕朝向的参考方格，再次点击恢复透视投影。切换保留观察方向、中心和目标平面的显示比例，不修改模型坐标；不同深度的牙齿会因投影变化而呈现不同的相对大小。
- 网格参照截图设计为浅灰细线与浅红粗线，覆盖画布及牙模；小格 1、大格 10 个模型坐标单位，不能自动认定为毫米。格线随正交缩放改变间距，过密细线会淡出。右下角标明投影模式与网格单位，导出 PNG 时包含已开启的网格。
- 左键拖动旋转，右键拖动按屏幕方向平移，中键拖动或滚轮缩放。滚轮向前放大。触屏单指旋转、双指缩放和平移。
- 采用固定竖直轴的环绕操作，旋转围绕可见模型中心；限制极点防止画面翻转，轻微阻尼平滑收尾。水平拖动从顶部视角仍围绕统一竖直轴旋转。
- 上颌面、正面、右侧、仰视、左侧、后视、下颌面按钮切换视角。左右侧按患者自身方向命名：右侧从患者右侧（-X）观察，左侧从患者左侧（+X）观察。上下颌面保留极小倾角以避免极点奇异。
- “全颌”筛选上颌或下颌；每个图层可独立显隐、移除、修改所属颌面。文件名含 upper/maxilla/上颌 或 lower/mandib/下颌 时自动分类；其他文件需手动指定。
- 拖入一个或多个 ASCII/二进制 STL 或 OBJ，或点击“选择牙模文件”，支持混合选择。每次上传替换当前整批模型，同时选择的上下颌文件会一起保留；取消文件选择不影响当前模型。单文件最大 150 MB；读取失败显示提示并继续处理本批其余文件，全部失败时回到上传页面。上传成功后切换至全颌显示。连续上传时仅显示最新一批，旧批次未完成的读取不会重新加入场景。
- OBJ 文件内的多个网格分组归入同一图层，并保留原始坐标。支持三角面、多边形面和负索引；忽略点、线、MTL 材质和纹理，统一使用沙金色材质，不读取外部资源。只有点或线、不含表面的 OBJ 会提示无法显示。
- 平滑、原始面片和线框显示，透明度调节，Y/Z 向上选择，以及三轴 90° 旋转。方向操作对所有模型整体应用。
- 底部支持适应窗口（F）、恢复初始视图、导出 PNG 画布截图；右上角可以隐藏模型面板。

模型保留原始坐标及上下颌咬合关系，不单独居中。默认输入坐标 Z 向上、前牙朝 -Y；其他模型可调整整体朝向。STL / OBJ 没有可靠的标准单位信息，界面尺寸使用原始坐标单位，不能自动认定为毫米。透明模型交叠可能出现实时渲染排序误差。

## 构建与验证

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

生产文件输出至 `dist`，预览地址 http://127.0.0.1:4186 。部署整个 `dist` 到静态 HTTP 服务，支持子路径；不支持直接双击 HTML 的 file 协议。测试覆盖真实示例解析、坐标关系、ASCII STL、损坏文件和颌面分类，以及 OBJ 分组、多边形、负索引、材质引用和无效模型。

`public/demo` 内的上下颌样例仅作为测试文件保留，来自工作区“竞品样例数据/原始数据”。如需查看，可通过上传入口手动选择，不再自动载入。

实现参考 [STLLoader 官方文档](https://threejs.org/docs/pages/STLLoader.html) 与 [OrbitControls 官方文档](https://threejs.org/docs/pages/OrbitControls.html)。
