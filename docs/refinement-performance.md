# 2026-10-13 分牙强平滑性能定位与优化

## 已确认的瓶颈

使用病例 `2087374889185972224` 的上下颌 OBJ 与原始 JSON，经前端同一个 `objTopology` / `packRefinement` 生成输入。对本轮修改前的 Python 源码快照和修改后实现分别计时，不使用预计算响应或降低模型分辨率。

旧实现逐条曲线执行 48 次平滑投影，最后再投影一次。Trimesh 4.8.3 的 `proximity.nearby_faces` 在每次调用时从整颌引用顶点重建 cKDTree。上颌 91 条曲线调用 4459 次，下颌 75 条曲线调用 3675 次；主要开销为曲面投影的重复索引构建和调用，而不是标签场求解。

| 项目 | 优化前 | 优化后 | 倍率 |
| --- | ---: | ---: | ---: |
| 上颌完整 process | 150.06 秒 | 21.51 秒 | 6.98 倍 |
| 下颌完整 process | 85.96 秒 | 17.48 秒 | 4.92 倍 |
| 双颌计算时间之和 | 236.02 秒 | 38.99 秒 | 6.05 倍 |
| 上颌投影耗时 | 145.27 秒 | 16.75 秒 | 8.67 倍 |
| 上颌投影调用 | 4459 次 | 49 次 | — |
| 下颌投影调用 | 3675 次 | 49 次 | — |

单次本机计时，存在系统负载差异，不作为所有病例的时延保证。上次浏览器 900 秒超时未记录排队和分阶段耗时，不能证明那 900 秒全部来自该瓶颈；本轮直接处理基线约 236 秒，不将历史超时作速度倍率分母。

## 实现

`server/refinement/curves.py` 增加 `smooth_chains`，每轮将各条曲线的投影请求合批，投影后仍按原曲线切片更新。每条曲线独立保留相邻点、开曲线固定端点、闭曲线首尾、0.25 加密间距、48 轮及 0.55 位移上限。其余 strong 参数、标签清理、标签场、划分与几何校验均未改变。保留单条 `smooth_chain` 兼容入口。

没有将上下颌同时计算、没有降低迭代次数，也没有跳过面积覆盖、标签保留、带外标签场或源面重建检查。批处理的中间内存随所有曲线采样点数增长；当前真实模型测试覆盖了 4 个不同牙模，但不宣称所有超大模型都已验证。

`service.py` 报告增加 `decode_seconds`、`curve_count`、`stage_seconds`（孤岛清理、界面提取、曲线平滑、场求解、划分、校验）；`app.py` 日志及响应头分别记录 `X-Refinement-Queue-Seconds` 和 `X-Refinement-Compute-Seconds`。后续可区分等待旧计算与当前计算慢。

健康接口返回加载时的源码 revision，启动脚本比较磁盘代码与运行版本；遇到旧服务或其他端口占用会报错提示重启，不静默复用旧代码，也不自动结束其他进程。本轮已核对进程归属并重启当前项目本机服务，优化已生效；未更改远端服务器。

## 正确性与完整链路

- 同一真实上下颌输入，优化前后响应数据区的 Float32 坐标、法线、Uint16 面片标签逐字节一致，只有报告头的新增计时等元数据不同。
- 4 个既有真实模型回归通过，输出面数依次为 267865、351612、226400、343864，区域顺序与 strong 原型一致。与原型坐标的最大差异仍为既有 Float32 重建误差，范围约 0.000322–0.000556 模型单位，本轮优化前后同输入并无该差异。
- 后端 17 项测试通过，包含独立旧算法数值对照、混合开闭曲线、短曲线、位移上限及空集合；投影次数回归保证多条曲线 48 轮只投影 49 次。前端 38 项测试和生产构建通过，仍有既有 Three.js 包体积提示。
- 不使用 EDIT_FIXTURE、没有 API 路由替换的真实浏览器回归通过。双颌约 49.3 秒就绪；两次 HTTP 200 的计算耗时分别约 25.6 / 20.8 秒，排队均为 0；随后实际进入四步编辑、编号修改、重置、保存、再进入以及退出/导入确认，无页面错误。此轮同时有独立模型回归在运行，故浏览器耗时高于单进程基准之和。
- M1 的本机真实强平滑返回、双颌编辑与保存路径已补齐验证。远端 GPU 自动推理未重新运行，不能将本地文件夹标签测试写为远端模型质量或远端完整链路验证。

计时、源码快照、输入及响应二进制均保存在已忽略的 `test-results/performance/`，未加入 Git。`comparison.json` 为双颌对比，`prototype-regression.json` 为 4 模型回归；浏览器结果在 `test-results/adjustment-browser.json`。这些文件仅用于测试，不是应用运行依赖。
