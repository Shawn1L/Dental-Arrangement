在线推理此前完成过上下颌样例调用及适配层测试，但用户反馈线上分牙仍有问题，当前默认流程使用已有本地结果。此次气泡修复和收尾没有重新评估远端服务或模型准确性。“调整分牙”、后续治疗步骤及本分支的咬合功能尚未实现。

## 2026-10-12 强平滑集成

分牙展示前统一调用本机 `/api/segmentation/refine`，固定采用原型 strong 参数。算法模块在 `server/refinement/`，前端二进制协议和拓扑映射在 `src/segmentation-refinement.mjs`。本地文件夹标签不经过远程推理；在线推理完成后也经过相同修正。检查原面面积覆盖、源面重建、带外标签场和标签保留，失败时禁止进入分牙。预处理和在线推理使用保留的原始网格，分牙才换用修正网格。清空/删除同时释放两份网格。

独立 Python 环境及启动方法见 README。不可使用兄弟原型目录的代码或预计算结果作为生产运行依赖。正在进行的 Python 运算不能即时停止，前端取消会忽略旧结果，服务等待其结束后再处理下一颌。


验证：前端 25 项测试、Python 13 项测试与生产构建通过。四个真实模型回归（原型样例 A 上颌、B 上颌/下颌、C 带矫治器上颌）分别输出 267865、351612、226400、343864 面，面片数量和区域标签顺序均与 strong 原型一致。重新从 Float32 输入重建曲线导致最大坐标差异约 0.000557 个原始模型单位；面面积覆盖与标签保留检查通过。回归记录保存在忽略目录 `test-results/strong-regression.json`，不加入 Git。
